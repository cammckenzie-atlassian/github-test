# 🐍 Snake Demo

A classic Snake game built with vanilla HTML5 Canvas and JavaScript — no dependencies.

## How to play

Open `index.html` in any modern browser.

| Key | Action |
|-----|--------|
| `Space` / `Enter` | Start / Restart |
| `Arrow keys` or `W A S D` | Change direction |

## Features

- Smooth grid rendering with subtle pulse animation on food
- Speed increases every 5 points
- High score persisted via `localStorage`
- Death flash effect
- Snake eyes that follow movement direction
